# Design

Scaffold apps/web as the accepted React/Vite TypeScript SPA. A restrained desktop sidebar and responsive top navigation group Projects, Roles, Execution and GitHub; session gate renders login before protected reads. URL hash stores selected view. Forms use native accessible controls and repository-owned shadcn Base UI Button; TanStack Query caches only authenticated reads. Scoped React state retains editor drafts when selection/view changes. No router/global-state/form framework is needed for four views.

Extract browser-safe AJV validation from the current Node-only protocol module into a shared validation entry with generated schemas/types. Do not ship fs/crypto/database/server modules. API adapter validates unknown JSON, sends credentials:same-origin, classifies deterministic errors vs uncertain transport, preserves exact immutable request IDs and queries/replays receipts. No session/token persistence. Mutations show pending state and invalidate the canonical snapshot only after a committed receipt. Global configuration version is captured when a draft is initialized, not refreshed under edits. Explicit reload discards/rebases only with a visible user action.

Use pinned React 19.3.0, Vite 8.3.1/plugin-react 6.1.1, TanStack Query 5.104.0, Base UI 1.8.0, Tailwind 4.3.3; all MIT and match the accepted stack. shadcn source preset is explicitly Base UI. Add only its Button and minimal class helpers required by generated source. Use @fastify/static 10.1.5 (MIT, matching Fastify 5) for reviewed static path/content-type behavior rather than custom file serving. Playwright is test-only for interactions/screenshots. Exact versions/lockfile are reviewed; build reports actual bundle size.

Backend serves immutable hashed assets and no-store SPA shell at /; API/WSS paths retain existing routing/authentication. Startup optional web directory in app construction keeps tests/native app import valid before web build. Container build produces web assets and includes them in the server image; test image still has full toolchain. Development uses Vite same-origin proxy; production uses backend HTTPS with Secure cookies.

Tests: browser app against real isolated PostgreSQL plus synthetic Owner credentials; API adapter unit checks validate responses, stale errors, unchanged-ID uncertainty recovery. Playwright interaction checks create/edit/reload/logout, retained drafts, mobile width/keyboard and controlled network response loss. Browser fixtures may provide deterministic Runtime/provider observations and errors; they must be labeled as fixtures. Live GitHub credentials and real Runtime execution remain separate evidence. Rollback removes only built assets; additive APIs/storage retained.
